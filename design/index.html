怎么选 & 实现要点

三套主题共用同一套实现约定，迁移成本很低。

主题气质最适合字体强调色
A · 清新翡翠 清爽、亲切、产品感 教程、入门向技术博客、个人主页 Plus Jakarta Sans + Noto Sans SC #0F9D58 / 暗 #34D980
B · 霓虹青柠 高能量、硬朗、态度鲜明 技术专栏、观点长文、独立开发者 Archivo Black + Inter + JetBrains Mono #7FC400 / 暗 #C7F53D
C · 森林墨绿 安静、刊物感、耐读 随笔、设计观察、长文阅读站 Fraunces + Noto Serif SC #4A6B52·#B5654A

主题切换怎么做的

在 <html> 上写 data-theme="light|dark"，所有颜色都是 CSS 变量，两套变量各写一次即可。切换只改一个属性，零重绘代价。

避免首屏闪烁

把读取 localStorage 与系统偏好的脚本放在 <head> 内联执行，早于样式渲染；并设置 color-scheme 让表单控件同步。

绿色系的对比度

浅色背景上用深绿（#0F9D58 系），深色背景上把绿色提亮到 #34D980 左右，正文保持 4.5:1 以上。绿色不做正文色，只做强调色。
