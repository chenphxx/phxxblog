12 套主题，每一套都有深色与浅色

左侧选主题，右侧就是套进你现有组件结构（站点头部、资料栏、终端会话、历史上的今天、贡献热力图、文章卡片、分页、按钮）之后的效果。预览页里的样式是从 frontend/src/styles/themes/*.css 原样抽取的，所以预览看到的就是换上去之后的效果。

默认主题是「预设」——中性灰阶 + 静蓝主色，令牌取自 VitePress + Teek 预设：深色底 #1b1b1f、深色卡片 #202127、品牌色 #3451b2 / 深色 #a8b1ff。另外 11 套绿色主题仍然保留，随时可切。

怎么用

项目里已经装好运行时切换：顶栏的主题按钮下拉里就是这 12 套，选完记在 localStorage，刷新后保持；旁边的圆形按钮单独控制深色/浅色。

增强层风格视觉语言包含的主题
minimal · 文档极简 中性灰阶、细边框、极淡阴影，无位移无硬阴影 预设（默认，VitePress + Teek 令牌）
soft · 柔和抬升 渐变主色、大圆角、多层柔和阴影 森屿绿洲 / 晨雾青 / 松涛墨绿 / 薄荷冰
hard · 硬朗位移 纯色主色、方正小圆角、偏移硬阴影、等宽标题 霓虹青柠 / 春芽黄绿 / 极光青绿
editorial · 编辑细线 衬线标题、极淡阴影、细线分割 苔原手记 / 抹茶奶绿 / 鼠尾草灰绿 / 青墨

1. 运行时切换（已实现）

顶栏主题按钮即可换色，圆形按钮切换深色/浅色。

// stores/theme.ts
theme.setTheme('cuanmu')
theme.toggle()   // 深浅色

2. 改配色

12 套主题由一份数据生成，改一个色值就全站生效。

// design/themes/tokens.mjs
primary: '#3a5ccc',
// 然后重新生成
node design/themes/generate-themes.mjs

3. 校验

自动检查令牌齐全、默认主题一致、WCAG 对比度。

node design/themes/audit.mjs
node design/previews/build-previews.mjs
design/previews/ · 预览与主题 CSS 同源，改主题后运行 node design/previews/build-previews.mjs 重新生成
